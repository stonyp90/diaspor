# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
verbatim.

## TL;DR

- Be respectful. Disagree on technical merits; never on the person.
- No harassment, discrimination, or personal attacks.
- Assume good faith. Ask before assuming malice.
- Maintainers may remove comments, commits, code, and contributions that
  violate this code.

## Reporting

Suspected violations may be reported privately by email to
**anthonypaquet1508@gmail.com**. Reports are confidential. Reporters
will receive an acknowledgement within seven days and a resolution
note within thirty days.

## Enforcement

Maintainers will apply the four-step enforcement ladder described in
the Contributor Covenant: correction → warning → temporary ban →
permanent ban. The decision is the maintainer's and is final for the
purpose of this repository.

## Scope

Applies to:

- Issues, pull requests, discussions, and review comments on
  github.com/stonyp90/stony-vdfs and codeberg.org/stonyp90/stony-vdfs.
- Direct messages from project participants framed as being about
  this project.
- Public talks or social-media statements where the participant
  identifies themself as representing this project.
