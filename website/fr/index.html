📌 Montez n'importe où.

Mémoire · local · FUSE (macOS/Linux) · WinFsp (Windows) · S3 · NAS/SMB · RTSP. Une API async. Un modèle mental.

⚡ Indexez sur place.

Le pipeline lit les fichiers là où ils sont. Étiquettes, transcriptions et embeddings vont dans un magasin de métadonnées séparé. Les originaux ne bougent jamais.

🔒 Pas-de-réseau par construction.

L'IC exécute tous les tests dans unshare --net. La compilation échoue si un module ouvre un socket sans opt-in explicite. Le contrat de confidentialité est structurel, pas aspirationnel.

La facture d'IA infonuagique

Ce que vous cessez de payer
  • Frais d'inférence au jeton, à la minute, sur chaque appel
  • Licences SaaS par siège qui grimpent avec l'effectif
  • Frais de sortie (egress) pour lire vos propres données
  • Une grappe GPU neuve à acheter, alimenter et opérer
  • Un compteur qui suit l'usage — récurrent, sans fin

Votre matériel

Ce que vous payez
  • Les serveurs, GPU et disques que vous exploitez déjà
  • Une licence forfaitaire, ajustée à votre volume de données
  • Zéro par appel · zéro par jeton · zéro egress
  • S'installe dans votre infra — ou s'y connecte directement
  • Évolue avec le matériel que vous contrôlez, rien d'autre

Les signaux de crédibilité ne sont pas de la détection de mensonge (plafond de précision scientifique ≈ 74 %, base humaine ≈ 54 %). Diaspor publie des fiches de précision par version. Verdicts forensiques, décisions d'embauche, adjudications d'assurance et décisions policières sont hors-cadre.
