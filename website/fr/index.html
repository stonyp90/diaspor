Les signaux de crédibilité ne sont pas de la détection de mensonge. Le plafond de précision dans la littérature scientifique pour l'inférence de tromperie sur vidéo est d'environ 74 %; la base humaine est d'environ 54 %. Diaspor publie des fiches de précision par version. Les verdicts forensiques, décisions d'embauche, réclamations d'assurance et adjudications policières sont hors-cadre et exclus par nos conditions d'utilisation. Les contextes de travail et d'éducation dans l'UE sont exclus en vertu du AI Act européen (en vigueur août 2026). Flux de consentement BIPA requis en Illinois.
Les scores et marqueurs sont des aides à la décision basées sur les signaux observés. Diaspor n'émet pas de verdict de culpabilité, de mensonge ou d'inaptitude. Restitution humaine obligatoire dans tout contexte légal, employeur ou disciplinaire.

Auto-hébergement

Vos données ne sortent jamais de votre périmètre.

Quatre modes de déploiement, du laptop hors-ligne au datacenter classifié. Vous choisissez le rayon d'isolation, nous fournissons le binaire signé, le Helm chart et les modules Terraform. Aucune dépendance à notre infrastructure pour opérer.

  1. 01 Isolation max

    Air-gap · Hors-ligne

    Binaire unique sur poste classifié ou serveur isolé. Modèles transférés sur clé USB signée. Aucun réseau requis.

    • Compatible salles SCIF / classifiées
    • Modèles vérifiés SHA-256
    • Zéro service réseau actif
    $ diaspor-agent serve --air-gap --models ./models.tar
  2. 02 Votre infra

    On-premise

    Votre serveur, votre datacenter, votre cluster Kubernetes. Helm chart fourni. Mises à jour atomiques par tag git.

    • k8s ≥ 1.28 · OpenShift compatible
    • GPU NVIDIA · AMD · Apple Silicon
    • Pas de pont sortant requis
    $ helm install diaspor diaspor/diaspor --version 0.1
  3. 03 Recommandé

    Votre tenancy nuage canadien

    Diaspor déployé dans votre compte AWS · Azure · GCP, région canadienne. Vous gardez les clés (BYOK), les journaux, la facture.

    • Modules Terraform officiels
    • BYOK · KMS · HSM
    • Co-géré ou auto-géré
    module "diaspor" { source = "stonyp90/diaspor/aws" }
  4. 04 Géré par Diaspor

    Notre nuage canadien

    Tenancy multi-locataire dans AWS ca-central-1. Pour cabinets qui ne veulent pas opérer. Chiffrement par locataire, isolation logique stricte.

    • SLA 99,9 % heures ouvrables QC
    • Mises à jour gérées par Diaspor
    • Modèle d'exploitation coût-plus
    $ diaspor login --tenant votre-cabinet
