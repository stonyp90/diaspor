L'intelligence des fichiers
sur votre matériel.

Diaspor est une plateforme d'intelligence des fichiers en Rust. Un seul navigateur de bureau pour chaque niveau de stockage que vous possédez — local · NAS · S3 · nuage · grappe GPU on-prem. Déplacez les fichiers entre niveaux sans copier-coller-renommer, recherchez par contenu et non par nom, suivez le CPU, GPU et disque de l'agent en direct. Rien ne quitte votre périmètre, par construction.

📌 Montez n'importe où

Mémoire · disque local · FUSE (macOS/Linux) · WinFsp (Windows) · S3 · NAS/SMB · RTSP. Une API async, un modèle mental.

⚡ Indexer sans copier

Le pipeline lit les fichiers en place. Étiquetage, transcription, embeddings vivent dans un magasin de métadonnées séparé. Les originaux restent sur leur backend.

🔒 Pas-de-réseau par construction

CI exécute tous les tests dans unshare --net. La compilation échoue si un module ouvre un socket sans opt-in explicite. Le contrat de confidentialité est structurel, pas aspirationnel.

💰 Payez votre matériel

Pas de facture cloud par-token. Votre CPU, GPU et disque font le travail. Diaspor évolue linéairement avec votre infrastructure — et rien d'autre.
