📌 Mount anywhere

Memory · local disk · FUSE (macOS/Linux) · WinFsp (Windows) · S3 · NAS/SMB · RTSP. One async API, one mental model.

⚡ Index without copying

The pipeline reads files in-place. Tagging, transcription, embeddings live in a separate metadata store. Originals stay on their backend.

🔒 No-network by construction

CI runs every test inside unshare --net. Build fails if any module opens a socket without explicit opt-in. The privacy contract is structural, not aspirational.

💰 Pay for your hardware

No per-token cloud bills. Your CPU, GPU and disk do the work. Diaspor scales linearly with your infrastructure — and nothing else.

FAQ

Answers procurement asks for

The questions every privacy officer, CIO, and security reviewer sends us first.

What does Diaspor do, exactly?

Three products on one Rust 2024 platform. Diaspor Desktop — a cross-platform app that auto-tags video archives, transcribes meetings on-device, and analyzes live streams. Diaspor Engine — a Virtual Distributed Filesystem with CLI, SDK and REST API, mounting local · FUSE · S3 · NAS under one async API. Diaspor Models — nine proprietary AI capabilities (auto-tag, transcription, vision, 3D pose, prosody, credibility, Judge Assistant, diarization, live stream) that plug into either.

Where does my data go?

Wherever you keep it. The Engine reads files in-place from whichever backend you mount — local disk, S3 bucket, NAS share, FUSE volume — without copying. Tagging, transcripts and embeddings go to a separate metadata store you control. If you opt into our Canadian cloud, everything runs in AWS ca-central-1 (Montréal), zero US sub-processors. CI proves it: every test runs inside unshare --net and the build fails if any module opens a socket without explicit opt-in.

What's the pricing model?

Desktop: 15 CAD/mo prosumer, 50 CAD/seat/mo team, 199 CAD lifetime. Engine: 5K CAD/yr per developer or 25–100K CAD/yr enterprise. Models: 25K+ CAD/seat/yr self-hosted or hosted SaaS. No per-token cloud bills — you pay for your hardware. Detailed quotes on request, scoped to volume and compliance posture.

Can I self-host?

Yes — that's the default. Single signed binary on a laptop. Helm chart for your Kubernetes cluster. Official Terraform module for your AWS · Azure · GCP tenancy. Air-gap mode for classified environments (models transferred via signed USB, zero network services). Our Canadian-cloud option exists for firms that don't want to operate, but every primitive is built to run in your perimeter.

Is the source code public?

No. Diaspor is closed source — proprietary runtime binaries, proprietary diaspor-* model weights, NDA-protected codebase hosted on a self-hosted private GitLab. Full source review is available under NDA for security teams. Internal use is unrestricted under our MSA; redistribution requires a commercial agreement. Builds are SHA-256 + Ed25519 (minisign) signed with SLSA build provenance.

What about Loi 25 / PIPEDA / Bill 96?

Aligned by design. Data residency in ca-central-1, PIA/EFVP template provided, built-in incident log, all 10 PIPEDA principles embedded in the architecture, bilingual UI/docs/support/AI for Bill 96 (OQLF-compliant), bilingual MSA pre-cleared for BSP and SQI procurement frameworks. SOC 2 Type II is in progress for 2026; interim evidence available under NDA.

How do I get Desktop / CLI / SDK?

Desktop: join the founding cohort for early access. CLI (the diaspor binary + diaspor-agent daemon): signed builds for macOS (Apple Silicon + Intel), Windows (x86_64), Linux (x86_64 + aarch64) — all minisign-verified, SHA-256 checksummed, reproducible from source, zero installer telemetry. SDK: cargo-installable for licensed embedders, with bindings for Rust, Python, TypeScript, Swift and Kotlin. Email us to scope an Engine licence.
